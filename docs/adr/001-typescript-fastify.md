# ADR-001. TypeScript + Fastify для API

**Контекст.** ТЗ требует типизированный контракт (OpenAPI), миграции в репозитории, CI с автотестами (§1). Команда уже пишет
Kassa на TypeScript (React + Node). Клиентов пять, все на вебе или React Native.

**Решение.** Node 22 + TypeScript (strict) на сервере. HTTP — Fastify 5 с `fastify-type-provider-zod`: zod-схема запроса одновременно
валидирует вход, типизирует обработчик и генерирует OpenAPI. Схемы живут в пакете `@dark/contracts` и используются клиентами напрямую.

**Альтернативы.** NestJS — больше церемоний (DI, декораторы) при той же модели; Go/Kotlin — второй язык в команде, типы контракта
пришлось бы дублировать или генерировать.

**Последствия.** Один язык и один источник типов. Платим производительностью CPU относительно Go — на 4 точки это не узкое место.
