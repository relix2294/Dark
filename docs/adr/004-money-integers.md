# ADR-004. Деньги и остатки — целые числа

**Контекст.** ТЗ §1: все суммы — целые дирамы (1 сомони = 100 дирам), никаких float для денег и остатков.

**Решение.** В БД — `integer`; в коде — `shared/money.ts` с проверкой целочисленности (`assertDirams`), округлением процентов
до дирама (`Math.round`), формулами итога и холда. Весовой товар: количество в граммах, цена за килограмм, сумма строки округляется.
В контракте тип `Dirams = z.number().int().min(0)`.

**Последствия.** Нет расхождений в копейках между корзиной, холдом, списанием и сверкой. Любое новое денежное поле — `integer` + `Dirams`.
