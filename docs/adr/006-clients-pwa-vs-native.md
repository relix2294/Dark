# ADR-006. PWA для сборщика и кухни, Expo для курьера

**Контекст.** Терминал сборщика — Android с аппаратным сканером, работа без связи до 30 минут (ТЗ §7). Кухня — планшет. Курьер —
геопозиция раз в 5 с в движении, пуши, накопление событий офлайн (ТЗ §6, §11). Витрина — веб-окно внутри DC Next.

**Решение.** Сборщик, кухня, админка, витрина — React + Vite (PWA где нужен офлайн: Dexie/IndexedDB, как в Kassa). Аппаратный сканер
отдаёт штрихкод как ввод с клавиатуры — браузеру достаточно. Курьер — Expo (React Native): фоновая геолокация в браузере недоступна.

**Последствия.** Один стек React для всех клиентов, общий пакет контрактов и UI-компонентов. Одно нативное приложение вместо четырёх.
