# ADR-007. Платежи за адаптером с заглушкой

**Контекст.** Контракт API кошелька DC не получен (ТЗ §5). Остальная система не должна ждать банк.

**Решение.** Интерфейс `WalletAdapter` (`hold / capture / release / refund / status`) в `modules/payments/adapter.ts`.
`StubWalletAdapter` реализует его в памяти, идемпотентен по ключу, детерминированно отклоняет и «теряет ответ» по суффиксу `dc_user_id`
для тестов сверки. Выбор реализации — переменная `PAYMENT_PROVIDER`. Открытые вопросы банку перечислены в `WalletCapabilities`.

**Последствия.** Сценарии оплаты и сверки тестируются без банка; реальный адаптер — один файл без изменений в `orders`.
