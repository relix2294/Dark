# Витрина клиента (storefront)

**Статус:** рабочий первый экран: вход по токену DC Next (dev), адрес по геолокации, каталог обоих брендов, корзина с промокодом, оформление с подтверждением PRICE_CHANGED, статус заказа по SSE с курьером, история. Дальше: карта адреса, модификаторы блюд, повтор заказа.

**Стек:** React 19 + Vite + TypeScript, PWA. Открывается внутри DC Next (веб-окно или мини-приложение — решает банк).

**Экраны первой версии:** Выбор бренда · адрес на карте · каталог и поиск · карточка товара/блюда с модификаторами · корзина · оформление · статус заказа с картой (SSE) · история · повтор заказа

**Запуск:** `pnpm --filter @dark/storefront dev` (прокси `/api` → `http://127.0.0.1:3000`). Сборка в `deploy/www` — `pnpm build:web`.

**Правила:**
- Типы и схемы запросов — только из `@dark/contracts`; HTTP-клиент генерируется из OpenAPI (`/docs/json`).
- Все изменяющие запросы отправляются с заголовком `Idempotency-Key` (UUID на действие пользователя).
- Деньги показываются из дирамов (`toSomoni`), хранятся и передаются целыми.
