# Приложение курьера (courier)

**Статус:** этап 0 — макеты экранов (ТЗ §9). Код появится после утверждения макетов.

**Стек:** Expo (React Native), Android. Фоновая геопозиция раз в 5 с в движении, пуши, накопление событий офлайн с метками времени.

**Экраны первой версии:** Смена · текущее задание · скан пакетов · маршрут · доставка и звонок через скрытый номер · «клиент не вышел» · заработок за смену

**Правила:**
- Типы и схемы запросов — только из `@dark/contracts`; HTTP-клиент генерируется из OpenAPI (`/docs/json`).
- Все изменяющие запросы отправляются с заголовком `Idempotency-Key` (UUID на действие пользователя).
- Деньги показываются из дирамов (`toSomoni`), хранятся и передаются целыми.
