# Админка и пульт старшего смены (backoffice)

**Статус:** рабочий пульт: заказы точки по статусам с ожиданием курьера, курьеры, ручное назначение с причиной, отмена, приём возврата, возврат денег; параметры точки; журнал действий. Дальше: каталог, цены, зоны, промо, персонал, график курьеров, отчёты.

**Стек:** React 19 + Vite + TypeScript. Десктоп и планшет.

**Экраны первой версии:** Пульт: все заказы точки по статусам · курьеры на карте · ручное назначение · отмена и возврат · тревоги. Админка: каталог · цены · зоны доставки · промо · персонал и роли · график курьеров · параметры · отчёты · журнал действий

**Запуск:** `pnpm --filter @dark/backoffice dev` (прокси `/api` → `http://127.0.0.1:3000`). Сборка в `deploy/www` — `pnpm build:web`.

**Правила:**
- Типы и схемы запросов — только из `@dark/contracts`; HTTP-клиент генерируется из OpenAPI (`/docs/json`).
- Все изменяющие запросы отправляются с заголовком `Idempotency-Key` (UUID на действие пользователя).
- Деньги показываются из дирамов (`toSomoni`), хранятся и передаются целыми.
