# Терминал сборщика (picker)

**Статус:** рабочие экраны: задание в порядке обхода ячеек с таймером, скан ячейки и товара с аппаратного сканера, количество и вес на цифровой клавиатуре, «нет на полке», ярлык пакета; приёмка по поставке и размещение с подсказкой ячейки. Дальше: офлайн-очередь сканов (IndexedDB), пересчёт, списание.

**Стек:** React 19 + Vite + TypeScript, PWA на Android-терминале с аппаратным сканером (ввод как с клавиатуры). Офлайн-очередь сканов до 30 минут в IndexedDB (Dexie).

**Экраны первой версии:** Вход по PIN · очередь заданий · сборка (ячейка → товар → количество, таймер) · замена · приёмка · размещение · пересчёт · списание

**Запуск:** `pnpm --filter @dark/picker dev` (прокси `/api` → `http://127.0.0.1:3000`). Сборка в `deploy/www` — `pnpm build:web`.

**Правила:**
- Типы и схемы запросов — только из `@dark/contracts`; HTTP-клиент генерируется из OpenAPI (`/docs/json`).
- Все изменяющие запросы отправляются с заголовком `Idempotency-Key` (UUID на действие пользователя).
- Деньги показываются из дирамов (`toSomoni`), хранятся и передаются целыми.
