# Экран кухни (kds)

**Статус:** рабочие экраны: очередь станции с цветами серый/жёлтый/красный, старт и готовность блюда, упаковка заказа с печатью ярлыка, стоп-лист. Дальше: WebSocket вместо опроса, выбор блюд из каталога в стоп-листе.

**Стек:** React 19 + Vite + TypeScript, планшет в ландшафте, WebSocket-очередь. Крупные элементы, работа одной рукой, без ввода текста.

**Экраны первой версии:** Очередь станции (pizza, grill, cold, pack) с цветами серый/жёлтый/красный · упаковка · стоп-лист

**Запуск:** `pnpm --filter @dark/kds dev` (прокси `/api` → `http://127.0.0.1:3000`). Сборка в `deploy/www` — `pnpm build:web`.

**Правила:**
- Типы и схемы запросов — только из `@dark/contracts`; HTTP-клиент генерируется из OpenAPI (`/docs/json`).
- Все изменяющие запросы отправляются с заголовком `Idempotency-Key` (UUID на действие пользователя).
- Деньги показываются из дирамов (`toSomoni`), хранятся и передаются целыми.
